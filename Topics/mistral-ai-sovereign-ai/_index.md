# Mistral AI と主権AI（Sovereign AI）

## Overview

欧州発のAI企業 **Mistral AI**（仏・パリ）を中心に、生成AIをめぐるグローバルな地政学的競争と「主権AI」の台頭を研究するトピック。2026年半ばの時点で、AIは単なるソフトウェアから国家の安全保障・経済競争力・文化的アイデンティティを懸けた戦略的インフラへと変質している。

## Key Questions

- [ ] Mistral AIのMoEアーキテクチャは、米国のスケーリング戦略に対してどこまで優位性を保てるか？
- [ ] オープンウェイトとプロプライエタリの「ハイブリッド戦略」は長期的に持続可能か？
- [ ] 欧州のAI主権は、実際に米中の寡占に対する有効なカウンターバランスとなり得るか？
- [ ] 産業用AI（Physical Simulation × AI）はMistralの次の主戦場になるか？
- [ ] Sakana AI（日本）の進化的アプローチは、Mistralのスケール戦略と補完関係を持つか？

## Findings

- Mistral AIは2023年4月創業から約3年で評価額140億ドル（欧州最速のデカコーン）
- MoE（Mixture of Experts）により、推論コストを競合比1/10に圧縮
- 三創業者ともDeepMind・Metaの出身で、Chinchilla則・LLaMAの開発者
- オープンウェイト＋API課金＋エンタープライズライセンス＋Vibeサブスクのハイブリッド収益モデル
- Emmi AI買収で産業用シミュレーション（航空・自動車・半導体）へ本格参入
- フランス軍・政府機関がMistralシステムを採用、欧州デジタル主権の象徴的存在に
