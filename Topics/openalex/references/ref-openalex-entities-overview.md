# OpenAlex Entities Overview

**URL**: https://developers.openalex.org/api-entities/entities-overview  
**提供元**: OurResearch（OpenAlex公式）  
**種別**: 公式APIドキュメント

## サマリー

OpenAlexの8エンティティ（Works/Authors/Sources/Institutions/Topics/Publishers/Funders/Countries）の概要とID体系の説明。OpenAlex IDの形式（`https://openalex.org/W...`）、外部ID（DOI/ORCID/ROR）との対応、dehydratedオブジェクトの概念を解説。

## キーポイント

- Topicsは4層階層（Domain→Field→Subfield→Topic）
- 2025年後半にXPAC追加（1.9億件、デフォルト除外）
- 外部IDを直接API URLとして使用可能
